# About Me

Hey there, I’m Max 👋

I’m a cloud and platform engineer with over a decade of experience building reliable infrastructure and automation. I’ve led small, agile teams that halved delivery times and reduced costs by more than 20%. I enjoy turning complex problems into practical systems that work well for everyone.

Outside work, you’ll usually find me tinkering with my homelab and home network, running AI models locally, experimenting with Linux, archiving the web, automating everyday tasks, or exploring retro games, handhelds and small-form-factor devices.

## Projects

- [homelab](https://github.com/maxexcloo/homelab) and [kubelab](https://github.com/maxexcloo/kubelab) run my home network and Kubernetes clusters, built with OpenTofu and Flux.
- [minilab](https://github.com/maxexcloo/minilab) is where I put small self-hosted apps. Merging one deploys it.
- [flylab](https://github.com/maxexcloo/flylab) runs outside monitoring for my homelab on Fly.io.
- [images](https://github.com/maxexcloo/images) builds the container images I use from pinned upstream sources.
- [studio](https://github.com/maxexcloo/studio) is my fork of a ComfyUI front end, with multi-user accounts and an MCP server so chat apps can generate images and video.
- [agents](https://github.com/maxexcloo/agents) holds the agent skills and guidance I use across my repositories.
- [tofusort](https://github.com/maxexcloo/tofusort) sorts and formats OpenTofu and Terraform files.
- [actual-up](https://github.com/maxexcloo/actual-up) syncs my Up bank transactions into Actual Budget.
- [Beszel](https://github.com/maxexcloo/homeassistant-beszel-integration) and [Energy Locals](https://github.com/maxexcloo/homeassistant-energy-locals-integration) are Home Assistant integrations I maintain.
- [trmnl-builds](https://github.com/maxexcloo/trmnl-builds) builds TRMNL e-ink firmware automatically, and you can flash it from the browser.
- [bluemax](https://github.com/maxexcloo/bluemax) is my custom Bazzite image for handheld gaming.
